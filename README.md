# clara_gimenez_bitacora
Repositorio que documenta el trabajo práctico de la materia Introducción a Ciencia de Datos realizado por Clara Gimenez.
| Carpetas | Uso |
|---|---|
| `data/` | CSV con los datos a analizar |
| `docs/` | Documentos formato excel, doc, md (descripción objetos caja misteriosa, multiple opción) |
| `graficos/` | Gráficos resultantes de scripts en formato png |
| `scripts/` | Scripts de código Python (archivos .py) |

| Otros archivos | Uso |
|---|---|
| `README.md` | Descripción del repo y su organización |
| `.gitignore` | Excluye CSV pesados que trancaban los push a GitHub |
